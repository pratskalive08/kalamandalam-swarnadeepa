# Kalamandalam Swarnadeepa — static site

A responsive HTML/CSS recreation prepared for GitHub Pages.

## Preview

```bash
python -m http.server 4173
```

Open `http://localhost:4173`.

## Site assets

The supplied landing-page, About, performance and gallery images are wired into
their matching sections. The navigation downloads the included portfolio PDF.

## Publish with GitHub Pages

Push this folder to a repository, then choose **Settings → Pages → Deploy from
a branch** and select the repository's main branch and root folder.
